# Лабораторна робота №4: Ієрархія класів та обробка тексту (ООП)

**Виконав:** Солом'яний Денис  
**Варіант:** NZK=20 (Модифікація ЛР №3)

## Функціонал та вимоги

### 1. Ієрархічна структура класів
Згідно з завданням, реалізовано наступну архітектуру:
*   **`Letter`**: Базовий клас для представлення однієї літери.
*   **`Word`**: Складається з масиву (списку) об'єктів `Letter`.
*   **`Punctuation`**: Клас для розділових знаків.
*   **`Sentence`**: Складається з масиву об'єктів `Word` та `Punctuation`.
*   **`Text`**: Найвищий рівень ієрархії, що складається з масиву об'єктів `Sentence`.

### 2. Обробка тексту
Програма виконує автоматичну нормалізацію вхідних даних:
- Всі послідовності **табуляцій** (`\t`) та **множинних пробілів** замінюються на один пробіл.
- Текст розбивається на структурні одиниці (речення -> слова -> літери) при створенні об'єктів.

### 3. Модифікація ЛР №3
Клас `NPC` адаптовано під нову систему:
- Поля, що раніше були рядками (наприклад, `name` та `place`), тепер ініціалізуються як об'єкти класів `Word`.
- Виконавчий метод проводить сортування за **рівнем** (зростання) та **здоров'ям** (спадання).
